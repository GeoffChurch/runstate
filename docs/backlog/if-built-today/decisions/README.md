# Decisions and retractions — `if-built-today/`

Companion to the layer documents in `../`. They state **conclusions**; the files here record, one per
layer, **what was tried, what was withdrawn, and why**, so that neither is re-proposed and neither has to
be re-derived. Split per layer on 2026-10-01; the entries are unchanged, and a reference to *"the
sketch"* means the single-file draft the layers came from.

Split out 2026-08-15. Before that, the sketch narrated its own corrections inline at 29 sites, which is
what made it read as unstable. The narrative is worth keeping — it is what stops re-proposal — but it is
not the design.

Refuted *ideas* with diagnosis live in `../../../dead_ends/`. These files are for decisions **inside** a surviving
design: things narrowed, reversed, or renamed.
